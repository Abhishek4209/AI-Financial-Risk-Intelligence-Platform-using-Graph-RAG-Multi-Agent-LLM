7. IMPORTANT: FRONTEND IP AND CORS
============================================================

The currently working frontend origin is:

http://10.171.1.112:5173

The backend CORS setting must include that exact origin:

$env:CORS_ALLOWED_ORIGINS="http://localhost:5173,http://127.0.0.1:5173,http://10.171.1.112:5173"

If your computer's LAN IP changes, update the IP in BOTH places:
1. CORS_ALLOWED_ORIGINS in the backend terminal.
2. The frontend URL you open in your browser.

After changing CORS settings:
1. Stop the backend with Ctrl + C.
2. Run the environment-variable commands again.
3. Restart Uvicorn.
4. Hard-refresh the frontend.

To find the current LAN IPv4 address, run:

ipconfig

Look for the IPv4 Address of the active Wi-Fi or Ethernet adapter.
Use that address in the frontend origin, for example:
http://YOUR_CURRENT_IP:5173

NOTE:
The VITE_API_URL shown above uses 127.0.0.1 and is correct when the
browser and backend are running on the same computer.
If you access the frontend from another device, configure VITE_API_URL
to use the backend computer's reachable LAN IP, and restart Vite.

9. TROUBLESHOOTING
============================================================

A. Backend page says connection refused
- Check that Terminal 1 is still running.
- Check the Uvicorn startup output for Python errors.
- Confirm port 8000 is listening:

  netstat -ano | findstr :8000

- Open http://127.0.0.1:8000/docs again.

B. Browser reports a CORS error
- Confirm the browser's frontend origin exactly matches an entry in
  CORS_ALLOWED_ORIGINS.
- The currently working origin is http://10.171.1.112:5173.
- Restart the backend after changing CORS_ALLOWED_ORIGINS.
- Check the existing CORSMiddleware configuration in src/api/main.py.
  Do not add duplicate middleware without inspecting the existing code.

C. Database connection error
- Confirm PostgreSQL is running.
- Confirm database name, username, port, and password.
- Recheck DATABASE_URL.
- URL-encode special characters in the password.

D. Frontend cannot reach the API
- Confirm the backend docs open at http://127.0.0.1:8000/docs.
- Confirm VITE_API_URL is http://127.0.0.1:8000 for same-computer use.
- Restart Vite after changing VITE_API_URL.

E. Port 8000 is already in use
- Check the process with:

  netstat -ano | findstr :8000

- Do not terminate an unknown process. Identify it first.

F. Frontend dependencies are missing
- From the frontend folder, run:

  npm install
